# Club Next runtime source

Original listener and bootstrap/configuration source associated with the captured Club Next application and its private HTTPS integration. This directory is separate from the [Next application source](../../apps/web/) and the [Common-shell Club/Member browser module](../../modules/club-member/).

| Source | Role |
| --- | --- |
| custom-listener/custom-listener.cjs | Original custom Node listener source. |
| native-origin/native-origin-config.append.cjs | Original fragment for the native origin configuration; not a standalone complete bootstrap. |
| bootstrap/private-app-bootstrap.template.cjs | Original application bootstrap template, separate from privately bound runtime output. |
| edge/CLUB_PRIVATE_TLS.append.caddyfile | Original private Club TLS routing fragment; not the complete shared edge configuration. |

[Exact source records](source-capture.json) link all captured original files and their existing source references. [Operations source](../../operations/club-next-runtime/) retains controller revisions, original patches and acceptance-program source. New Common-origin35 completion/adoption revisions remain in the existing operations/member-origin35/adoption area.

The original owner review records identify exact controller source hashes, and the corresponding observed Root records returned success. These are source/execution relationships, not independent full application acceptance or proof of current container/image parity. The migration owner reported configuring private HTTPS; subsequent application verification remains separate.

These original files retain absolute paths, configuration fragments, environment assumptions and protected runtime dependencies. This archive executes none of them. Private CA/key bodies, issued leaf-key bodies, bound credentials, private bootstrap payloads, live approval/window records and user data are excluded.

The directory is not a complete standalone runtime or installation recipe. Full base edge/bootstrap configuration, original protected projection/rendering code, exact dependency/image versions and original notices, all later changes and full recovery/source-offer closure remain under reconciliation. Original source and component licenses apply; no new blanket license grant is introduced.
