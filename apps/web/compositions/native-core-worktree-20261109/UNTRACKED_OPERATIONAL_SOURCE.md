# Original Core operations and qualification sources

This slice preserves 80 original operation and qualification programs: native source loaders and qualification controllers, synthetic command and attachment tests, business-journey tests, OCA migration wrappers, persisted-operation registration scripts and related source tooling. Original paths, modes, byte counts and hashes remain recorded in untracked-operational-source.json.

These are archived source programs. No tests, qualification controllers, migration wrappers, package installers, product builds or runtime commands were executed during capture. Python source was parsed only for syntax; importing or running the archived controllers is outside this preservation work. Original historical admission, lease, release and production gates remain in the source and supply no new execution authorization.

These files supplement the tracked Core source and other untracked source slices. Their referenced fixtures, databases, private deployment bindings, original dependency implementations and complete original notices remain distinct recovery requirements. Synthetic test labels are not production customer records. Existing notices remain applicable and no blanket replacement license is introduced.
