# Original programs retaining their source locations

This slice preserves 56 additional original source programs and controllers. Their absolute path literals identify original source files, technical runtime locations or private configuration inputs. These locations remain unchanged to preserve the actual program logic and source relationships. The referenced private configuration, credentials, gateway state and log contents are not included. File paths, hashes and original modes are recorded in untracked-source-location-programs.json.

The preserved files include historical qualification controllers, native server tools and Personal baseline-bootstrap source. The existing nonsecret Auth0 native client identifier in the original connection helper remains distinguished from a credential. No archived source program, product test, lease controller or runtime command was executed. Python syntax was parsed without importing the programs.

The source remains an additional historical worktree slice. Its private inputs, dependency implementations, complete original notices and present runtime equivalence remain separate requirements. Existing notices continue to apply; no new license or execution approval is granted.
