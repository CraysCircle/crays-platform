# Original technical source catalog

This slice retains 199 qualified original schema, factory/helper, fixture/configuration and technical-manifest/document files. Each original path, mode, byte length and SHA-256 is recorded in untracked-technical-source-catalog.json. A separate SQL fixture with five fixed identity subjects is represented by a protected source template and is excluded from this raw-source catalog.

The source manifests record historical versions, code hashes, artifact locations and qualification boundaries. They do not copy referenced private evidence, transcripts, audio or current customer state, and they do not turn an original acceptance marker into current runtime or legal acceptance. No source program, SQL, test, factory, installer or runtime was executed.

Exact imported sources, original notices, generated-client authority and full recovery remain component-specific work. No blanket replacement license is introduced.
