# Original generator and rollback sources

The original isolated GraphQL generator, its package manifest and exact lockfile, schema-baseline metadata, and eight rollback migration programs are preserved with original paths and hashes. Source preservation did not execute the generator, install dependencies or apply migrations.

The generator reads the three SDL sources declared in its implementation and produces resolver types. This does not establish the provenance of the separately held generated GraphQL client sources. The lockfile records four direct versions and 41 dependency packages; original dependency notice closure remains open. Package license metadata is evidence of declared metadata and does not replace original license texts.

The rollback programs retain their original data-preservation and fail-closed conditions. Their presence is source documentation and supplies no authorization to execute them. The preserved files are an additional source slice, not proof of a complete restorable Core installation or accepted runtime.
