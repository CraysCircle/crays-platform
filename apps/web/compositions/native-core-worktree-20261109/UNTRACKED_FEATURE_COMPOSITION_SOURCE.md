# Original feature composition and integration source

This slice preserves 157 original feature composition, integration and source-test files from the exact Core worktree. It covers speech, cited research, weather, translation/video, preferences, original-text capture, transcript drafts, personal planning and document integration. Source paths, original modes, hashes and identical-body relationships are recorded in untracked-feature-composition-source.json. Historical ORIGINAL, PROPOSED and candidate versions retain their actual paths.

Compiled native/upstream overlays, instrumented server startup code, the WhatsApp response-policy override and all flagged inline personal-data contexts remain outside this slice. Runtime customer messages, account records, private credentials and materialized state are not copied. No feature provider, materializer, source test or archived program was executed.

Preserving integration code does not establish complete upstream implementation, exact original dependency notices, artifact custody or runtime acceptance. Existing notices continue to apply and no new blanket license is introduced.
