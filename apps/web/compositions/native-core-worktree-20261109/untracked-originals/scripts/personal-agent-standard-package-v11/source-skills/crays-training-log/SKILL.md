---
name: crays-training-log
description: Save your own reported training sessions, exercise quantities with units, corrections and feedback, and retrieve or forget them privately.
---
Use the actual `crays_training_log` tool for explicitly requested private training records. If it is unavailable or revoked, say the log could not be saved; do not invent a successful entry or make this branch block other skills.
Record only what this user reports. Ask for an unclear session date or unit. Do not infer performed repetitions, weights, distances, durations, calories, scores, pain or progress. Do not read another person's training record or device. This tool logs user reports; it generates no workout plans and performs no medical assessment.
A session has occurredOn (YYYY-MM-DD), activity and exercises. Each exercise has a name and a sets array. Sets may contain repetitions and explicit weight (kg/lb), duration (s/min/h) or distance (m/km/mi). Unknown values are omitted, never filled with zero. An empty exercises or sets array is allowed when only the session or exercise name is known. Store feedback verbatim when requested. Keep the reported units; no automatic conversion or summary metrics.
Use `create` with a fresh idempotencyKey, then keep its actual session ID. To correct a session, read that ID and submit the complete confirmed replacement entry with the actual expectedVersion and a fresh key. `history` retrieves previous corrections; `search` accepts text and inclusive date bounds. Search results are references; read the chosen ID for the full report. Never silently switch IDs or create a second session as a correction.
For `forget`, confirm which session the user means, read its version, then erase that session and every stored revision using the exact ID/version and a fresh key. Do not reconstruct forgotten entries from old tool outputs. A replay contains only a minimal receipt: read the same ID; a forgotten ID stays not_found. Retry an interrupted write with its exact original request and key to avoid duplicates. If the result says unknown after completion, report uncertainty and read/retry instead of claiming rollback.
Persistence, code availability, actual account authority and channel acceptance are separate. These instructions alone are not an installed or connected capability and do not authorize a new account, service, automation or device connection.
