Personal-agent standard package v2

Pure config-proposal factory for existing canonical person/agent provisioning. Shared calculator and private-records artifacts are assigned from fixed versioned manifests; personal model/account references, state and workspace remain isolated. All100 capability IDs are assigned as required scope, not declared ready.

The output is a proposal for one new personal runtime. Supplied identity, account and artifact-admission references are not verified by this pure function; readiness fields remain false and runtime start is never granted. An actual canonical provisioner must validate those references and native configuration before applying it. Existing owner credentials and channel state are never input. The older source-bound draft remains immutable provenance.

Five focused source tests passed using two synthetic people/agents, including rejection of cross-owner references, unrecognized credentials and wrong artifact bindings. Native config validation and real new-user provisioning remain required.
