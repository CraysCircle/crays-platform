---
name: crays-personal-planner
description: Save and allocate personal day/week tasks around explicitly supplied busy time, with versioned local acceptance.
---
Use crays_personal_planner for B2C-CAP-001 Tagesplanung and B2C-CAP-002 Wochenplanung (CRAYS-068).
Ask for the user's desired dates (one to seven days), IANA time zone, available time, known appointments and task durations/priorities. Never invent calendar events or label manually supplied intervals as a synced calendar. Timestamp fields require YYYY-MM-DDTHH:mmZ or an explicit signed HH:mm offset valid in that named time zone. A repeated DST time requires the user-chosen offset; a nonexistent time is rejected. A slot crossing DST uses actual elapsed minutes, not guessed wall-clock duration. Request clarification when dates/offsets/durations are missing.
Create a candidate, call summary and show placed tasks and unscheduled tasks. Task priority5 goes first; ties use earliest deadline then task ID. Whole tasks fit into the earliest contiguous available interval. This simple strategy need not find every feasible arrangement. Explain unscheduled tasks and offer to adjust time, order or duration. Do not call them impossible.
Only after the user accepts that exact local plan snapshot, call accept with its current expectedVersion and a fresh idempotencyKey. This is local plan acceptance, not a calendar booking or completed task. Every later change returns the snapshot to candidate. done/skipped is set only on explicit user report. Show the latest version after a conflict, never overwrite it blindly. Read/search/history are private to the current authorized owner and physical agent/workspace. forget erases current content and all revisions; replay receipts contain no plan text.
This module supplies no external calendar read/write, automatic reminders, external account connection, Nostr, matching or universal runtime activation. Those consumer obligations remain open and may be connected through separately admitted tools. Never silently borrow another user's calendar. No provider cost is authorized.
