This directory preserves two exact Member application input versions inside the existing shared web project. It reuses unchanged source from the immutable shared baseline and retains every required changed source body here. It does not replace the prepared Club source tree in apps/web.

The two manifests, original-source.json and aws-build25-source.json, list every original path, byte count, SHA-256 and storage reference. The prepared Club tag includes a separately declared pool change and is not substituted for this original baseline.

## Layout and protected inputs

- current-overrides/ retains original AWS source variants.
- original-preimages/ retains earlier original source variants before AWS adaptations.
- baseline-protected/ retains templates for reused baseline files containing the same protected test bindings.
- post-build-config/ retains the two configuration files subsequently generated by Next.js; these are not the original build inputs.
- materialize.py reconstructs either exact input composition, without running the application.
- verification.json records the source-only reconstruction checks.

The bundle contains 82 unchanged original source bodies and 25 source templates, plus the two generated configuration files. The templates preserve original program logic and replace only two fixed test-binding values with named markers: MEMBER_TEST_ACCOUNT_ID and MEMBER_TEST_SUBJECT_SHA256. Their public-demo classification is unresolved, so no additional raw values are published by this capture.

The same markers are handled consistently in reused baseline variants. Their presence in an older public source version is not treated as consent or as proof of the account's public-demo status. This capture does not rewrite the retained source history.

## Restore the exact source

Use Python 3.9 or newer and Git. First obtain the protected JSON inputs through the source owner's approved recovery channel; never add that JSON to Git. A separately protected, encrypted off-server backup of these two source inputs has been read back and verified. This is separate from runtime credentials, customer data and database restoration.

From an existing complete crays-platform clone, restore to a new directory outside any Git checkout:

    python3 apps/web/compositions/member-source25/materialize.py \
      --repository . \
      --composition aws-build25 \
      --bindings-file /protected/member-source-bindings.json \
      --destination /outside-git/member-source25

Use --composition original for the 1,399-file original view. The destination parent must already exist. The tool needs the recorded baseline commit locally; it does not fetch from a provider or install dependencies.

Before creating the destination, the tool checks all exported source files and reconstructs every protected template. It verifies all resulting original byte counts and SHA-256 values. Missing or wrong protected inputs, an existing destination, a destination inside Git, or a symlinked destination are rejected. Restored files are created with owner-only permissions.
