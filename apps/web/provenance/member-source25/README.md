# Member source25: source, build and dependency evidence

This record distinguishes the original Member application, its materialized AWS inputs and the prepared shared Club capture. The files here are provenance; they do not replace the application-root package manifest or select a current production release.

## What was checked

The [source manifest](source-files.json) records 1,399 original Member input files and 1,401 AWS Member25 input files. Both source compositions were reconstructed privately and every file's original SHA-256 and byte count was verified: 2,800 comparisons. This includes the original preimages of AWS changes.

The [build record](source-build-binding.json) confirms that all 1,401 captured AWS input hashes match the owner's recorded successful build input manifest. The recorded Next.js build ID is wUKFmu0-AhQgD3tntumrG. A framework build ID is not a Docker image ID or registry digest. Runtime adoption and a complete source-to-current-image binding remain separate.

Next.js changed tsconfig.json and next-env.d.ts during that build. Their later generated bytes are preserved separately in the source intake and must not be confused with the original build inputs.

## Exact dependency records

The [original Member project lock](package-lock.original.json) matches the application's dependency declarations and all 47 observed directly installed package versions. Its SHA-256 is recorded in [dependency bindings](dependency-bindings.json). This is an original source lock, not a newly generated install result, and it does not silently replace the prepared Club capture's borrowed dependency provenance.

The 47 original installed package manifests and 41 installed root notice files were compared byte-for-byte with the existing shared third-party catalog; all 88 are already present. The binding record links those exact files instead of duplicating them. Version-bound original notice texts are located for 45 of the 47 direct packages. The existing server-only and drizzle-kit notice questions remain open.

A matching direct-package list does not establish complete transitive/bundled dependency source recovery, font/media rights, Node/container/runtime notices, application authorship rights or applicable source-offer closure.
