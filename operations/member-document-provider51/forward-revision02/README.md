# Member document provider51: Forward02 source and ingress

This folder preserves four exact Root-authored operational source files: the Forward02 same-created-family controller, namespace-lifetime verifier, revision04 generation finisher and separately pinned ingress51 controller. It contains source, not private execution inputs or an invitation to replay an operation.

## Read the source

- [Forward02 controller](recover_same_created_member51_family.forward02.candidate.py): continues the specifically created Member/Common/Work family without replaying container creation, archival, naming, registry or witness setup.
- [Namespace-lifetime verifier](verify_lifetime_member51_namespace.candidate.py): distinguishes prior process lifetimes and destroyed sandboxes from a later namespace that reuses a numeric inode.
- [Revision04 finisher](finish_current_member51_generation.rev04.candidate.py): preserves the original ordered 64 public-source / 62 policy-source generation closure, updates the Member51 registry row, checks physical process/socket ownership and publishes the exact successor control chain.
- [Ingress51 controller](member51_current39_ingress.candidate.py): validates the separately bound current family and the exact seven-block close/reopen projection while retaining other sites and the existing Caddy container/configuration relationships.

[The source capture map](source-capture.json) records full hashes, sizes, original paths and restore targets. The first three files are listed by the original Forward02 manifest; ingress has a separate explicit full-SHA Root authority. Historical recovery revisions are outside this four-file scope.
