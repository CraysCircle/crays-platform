# Club Next build, binding and private HTTPS operations

These are original source programs and patches from the Club build28 and subsequent origin/listener/private-HTTPS work. Original filenames and distinct revisions are retained. Publication preserves code; it does not authorize execution or repeat any runtime work.

| Area | Retained role |
| --- | --- |
| build28 | Original bounded build controller and memory/namespace source delta. |
| runtime-binding | Original existing-runtime binding controller, second revision and both original source patches. |
| native-origin | Original native-origin restart controller revisions and network/lifecycle delta. |
| listener-binding | Original custom-listener binding controller and its original patch. |
| private-tls | Both original append-only private TLS controller revisions. |
| acceptance/native-origin | Original application acceptance-program source for the native configuration. |
| acceptance/private-https | Later original acceptance-program source for the private HTTPS configuration. |
| dependencies | Exact referenced original pool helper and legacy Org installer helper source. |

The [listener/bootstrap/edge source](../../services/club-next-runtime/) is separate from these controllers. Three later Common-origin35 completion/adoption files extend the existing [Member-origin35 adoption source](../member-origin35/adoption/); eleven unchanged source bodies are referenced by immutable commit rather than copied again.

The capture includes 35 original source files: 24 new bodies plus 11 already-public byte-identical bodies. Twenty-three Python programs were syntax-parsed without importing or executing them. Source-only capture preserves original formatting and patches. The [source capture](source-capture.json) records original hashes and individual owner-code pin relationships.

The original controller reviews bind exact source hashes. The corresponding Root return records were observed separately. Historical source, owner approval, actual execution, private HTTPS setup and full application acceptance remain distinct evidence; this import does not infer a deployment from a candidate filename or successful syntax parse.

These programs can build images/artifacts, replace or restart containers, change private edge routing, manipulate leases or verify account-backed behavior when their original owner runs them. Original build/source manifests, protected projections, approved windows and current owner state are required; source publication is not a portable command sequence.

Live approval templates/records, source fences, runtime registries, private digests unrelated to source integrity, certificate/private-key bodies, credential values and application/user data remain outside this source export. Additional runtime/dependency programs referenced by the originals, complete current image/source relationships, original third-party notices, corresponding-source requirements and full recovery remain open.
