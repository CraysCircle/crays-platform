# Original Vendure asset controller: TypeScript source

Read [original-source.ts](original-source.ts) for the authored TypeScript input associated with the [published asset controller](../original-asset-delivery-controller.compiled07.rev02.cjs). It defines the native GET/HEAD controller and plugin, checks native asset/channel permissions and returns the original stored file bytes. It imports framework APIs; it does not include the NestJS/Vendure/Express implementations or private asset data.

The original source is 3,574 bytes. The source contract stores it in the source field. Its original filename was not recorded: original-source.ts is a preservation filename, not a claimed original project path. No TypeScript was regenerated from emitted JavaScript.
