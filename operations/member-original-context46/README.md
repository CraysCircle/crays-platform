# Member/Main/Common Source46 operating sources

This archive preserves the exact reviewed operating programs supplied for the Source46 build and installation flow. It is source preservation: publication does not execute, install or authorize these programs, and does not establish that private runtime adoption succeeded.

The corresponding [Member/Common application sources](../../services/member-identity/provider-account/source46/README.md) were preserved at commit [ef3a04f](https://github.com/CraysCircle/crays-platform/tree/ef3a04f101ba675028e97d5fcf95848e3883ad4b/services/member-identity/provider-account/source46). The older [Source42 operating sources](../member-provider-account42/source-cases/README.md) remain unchanged.

## What is here

| Directory | Captured responsibilities |
| --- | --- |
| `build/` | Original build controller and Root resource-window wrapper, original review proposal and the exact source-guard/provenance input containing the 28 base-source pins. |
| `install/` | Original stage, classification, environment projection, successor-payload, lifecycle, anchor-generation and finishing programs; retained listener/probe sources; the four-phase Root window wrapper. |

There are fifteen original files: thirteen programs and two build-source metadata files. The source map records every original absolute path, byte length, SHA-256 and exported representation. Original formatting, filenames, import dependencies and internal path references are retained.

Four files reuse already preserved Source42 bodies: the Source42 classifier, anchor-generation program, listener and anonymous probe. The anchor-generation file was renamed for46 but its original bytes are unchanged. A renamed file is not evidence of new implementation.

The matching Common candidate is referenced at its immutable application-source commit rather than copied again. The Common body hash is `0fded17840166bb8b992bb3e1708a4c566cb56f182cd239d44f2327f874c8e7c`.

## Relationships and prerequisites

These programs express the reviewed transition from the existing42 family to46. They preserve checks for original-source fences, the shared resource lock, exact review/build/source pins, private approval inputs, role/tenant boundaries and physical process/cgroup return. The environment projector describes five existing Main-purpose keys; its source is not the private environment or the values of those keys.

The code references separately supplied original build inputs, runtime registries, own helper modules, private approvals and protected state. Those path references are source relationships; the referenced private bodies are not included. This is not a standalone installation kit or a command sequence to run against another server.

The original build proposal is retained as historical pre-execution source metadata. Its unbound-resource/approval fields describe the proposal when written, rather than the latest build or deployment outcome. Source review and publication are separate from Root's actual resource admission, completed-build receipts and runtime adoption.

## Source and privacy boundary

No deployment environment, credentials, principal-policy body, cookies, authentication-session state, customer records or database contents was read or included by this preservation task. Ordinary program paths, public provider endpoints, environment-variable names and technical source guards are retained as code.

Exact file representations and any protected recovery requirements are recorded in [source-capture.json](source-capture.json). Neither this archive nor the existing Source42 archive proves complete current runtime, asset, dependency or server-loss recovery coverage.
