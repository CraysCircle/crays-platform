Read their preserved preconditions and obtain a separately authorized current operating plan before execution. The retained blocked revision is historical source, not a recommended entry point.

## Recovery and validation

Use a full Git clone and compare files with the source manifest. Original source formatting and bytes are retained; the local attributes preserve source line endings on checkout. Reusing these programs on another server also requires the qualified images, original runtime dependencies, protected inputs and a fresh owner-approved state binding. Their absolute paths and old receipt assumptions are not silently rewritten by this capture.

All eleven Python files were parsed without executing the programs. All twenty selected source/dependency inputs passed the recorded secret scan. Those checks do not prove runtime behavior, successful continuation, complete recovery or license clearance. This GitHub capture did not run any preserved application, preflight or operations program.
